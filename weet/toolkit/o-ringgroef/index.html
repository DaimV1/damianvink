O-ringgroef.

Groefdiepte t en groefbreedte b bij de vijf ISO 3601-1-koorden. Schema voor radiale en axiale inbouw. Nominale maten.

Groef: Dichtomatik-aanbeveling bij DIN ISO 3601, geen letterlijke ISO 3601-2-tabel. Geen vervanging van de norm of de leverancier.

Doorsnede

Geen schaal. t = groefdiepte, b = groefbreedte, d₂ = koord.

Groefmaten

Alleen ISO-koorden A–E. t +0,05 mm, b +0,25 mm (Dichtomatik). C = inloop/afschuining, alleen bij radiale groef.

Rekenhulp

Let op

  • Dichtomatik: groefvulling circa 70–85 % (niet bij vacuüm). Statische samendrukking 15–30 %.
  • Rek op de binnendiameter na montage max. circa 6 %.
  • Hoge druk: steunring; maten daarvan staan hier niet.
  • Binnendiameter d₁: ISO 3601-1, niet in deze tabel.

Vragen

Wat is d₂?

Koorddiameter volgens ISO 3601-1. Vijf groepen: 1,80 / 2,65 / 3,55 / 5,30 / 7,00 mm.

Groef voor 2,65 mm radiaal statisch?

t = 2,0 mm (+0,05), b = 3,6 mm (+0,25). Nominale samendrukking ongeveer 25 % — geen plus-mintolerantie.
