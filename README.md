# damianvink.nl

Persoonlijke site van Damian Vink. Statische HTML op GitHub Pages.

## Structuur

- `/` — Home (Wie ik ben · Wat ik doe · Wat ik denk · Contact)
- `/over-mij` — Wie ik ben + CV
- `/doe/marathon/` — Marathon-dashboard (Strava-export in `data/strava.json`)
- `/doe/projecten/` — Projecten (leeg tot er echte cases zijn)
- `/weet/` — Wat ik denk
- `/weet/toolkit/` — Engineering toolkit
  - `/weet/toolkit/passingen/` — ISO 286
  - `/weet/toolkit/spiebaan-toleranties/` — DIN 6885-1
  - `/weet/toolkit/bronnen/` — CAD en naslag

Oude paden:

- `/tools.html` en `/kennis/...` → `/weet/toolkit/` of `/weet/`
- `/weet/toolkit/richtlijnen-kanten/` → Bronnen (plaatwerk)
- `/weet/toolkit/iso-veiligheidsafstanden/` → toolkit-index (geen tabellen tot er gecontroleerde inhoud is)
